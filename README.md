# ヒマノワ

「暇を、遊びに変える。」をテーマにした、短時間で楽しめる暇つぶしポータルです。

## 収録コンテンツ

- キーボードゲーム：タイピング彗星、アロー・ドリフト、オービット・ガード、キー・コーラス
- ミニゲーム：秒速リアクション、カラー・クラッシュ、星座の記憶
- 診断：暇つぶしタイプ診断、今日の脳内天気
- 気分転換：無限プチプチ宇宙、ひと息オービット、究極じゃない二択
- ひらめき：ひらめきガチャ、一行タイムカプセル

ゲームの記録、獲得した sparks、連続プレイ、デイリーミッション、称号、カプセル、お気に入りはブラウザの端末内に保存されます。各コンテンツには操作方法の説明があり、`/` で検索、`?` でヘルプ、`Esc` でホームへ戻れます。

## 開発

```bash
npm install
npm run dev
```

品質確認は `npm test`、`npm run lint`、`npx tsc --noEmit` で行えます。
